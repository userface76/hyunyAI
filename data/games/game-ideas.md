# 시현 게임 아이디어 모음

상태: **계속 추가되는 아이디어 보관함**

## 1. 현이마을: 함께놀아요!
- 장르: 초반 친근함 → 후반 공포
- 이동: WASD 또는 방향키
- 상호작용: 클릭 또는 E
- 10~20분 정도의 짧은 챕터형 2D 게임으로 발전 가능
- 검은현이 클릭을 공포 전환 트리거로 사용

## 2. 변신로봇 게임
- 로봇을 직접 조립
- 차량 ↔ 로봇 변신
- 부품을 이모티콘이 아니라 실제 로봇 디자인으로 보여주기
- 미니카 조립 게임과 결합 가능

## 3. 종이로봇 경기
- 실제 종이로봇끼리 겨루는 놀이
- 자석이나 단순한 기계구조로 움직임을 만들 수 있는 방식 탐구
- 손으로 조종하는 방식과 경기 규칙을 함께 설계

## 4. 육각 숫자 타이밍 게임
- 육각형 구조의 숫자판
- 제한시간 약 30초
- 숫자를 빠르게 찾아 누르는 방식
- 약 20개 단위 라운드 아이디어

## 5. 숫자타워
- 마작처럼 여러 숫자 블록이 쌓인 화면
- 같은 숫자 3개가 모이면 제거
- 하단 보관칸에 선택한 블록이 쌓임
- 보관칸이 가득 차면 실패하는 방식
- 한 판을 짧게 끝낼 수 있도록 라운드/종료 규칙 필요

## 6. 미니카 조립게임
- 여러 부품 중 원하는 파츠를 골라 미니카를 조립
- 완성한 미니카를 테스트/경주시키는 방향
