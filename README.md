# hyunyAI

시현이가 만들고 싶은 **게임, 이야기, 세계관, 캐릭터, 종이로봇·만들기 도안 아이디어**를 계속 저장하고 다시 꺼내 이야기할 수 있게 만드는 전용 AI 친구 프로젝트입니다.

## hyunyAI가 하는 일
- 시현이가 만든 세계관과 캐릭터를 기억한다.
- 게임 아이디어와 규칙을 저장하고 다음에 이어서 발전시킨다.
- 종이로봇, 변신로봇, 공작 도안 아이디어를 기록한다.
- "그거 어디까지 했지?"라고 물으면 이전 설정을 찾아 이어준다.
- 서로 다른 세계관을 허락 없이 섞지 않는다.
- 확정 설정과 아이디어 후보를 구분한다.

## 데이터 구조
- `data/worlds/` : 세계관
- `data/games/` : 게임 아이디어와 규칙
- `data/making/` : 만들기·도안
- `data/characters/` : 캐릭터 색인
- `data/memory/` : 창작 기억 색인
- `prompts/` : hyunyAI의 기본 행동 규칙

## 운영 원칙
새로운 아이디어가 나오면 기존 파일에 이어서 기록합니다. 설정이 바뀌면 최신 설정을 우선하되, 중요한 과거 설정은 변경 이력으로 남깁니다.

> 이 저장소의 첫 자료는 지금까지 시현이와 나눈 창작 대화를 바탕으로 만든 초기 이관본입니다.
